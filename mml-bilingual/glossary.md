# MML 术语表（全书统一，翻译代理必须遵守）

规则：
1. 下表术语在译文中必须使用给定中文译法。
2. 术语在每章首次出现时写成「中文（English）」格式，其后只用中文；缩写词（PCA、SVD 等）保留英文缩写。
3. 数学符号、公式、变量名、公式编号（如 (2.3)）一律不翻译。图表编号不译。
4. 结构性引用的译法：Chapter 8 → 第 8 章；Section 3.8 → 3.8 节；Figure X.Y → 图 X.Y；Table X.Y → 表 X.Y；Example X.Y → 例 X.Y；Theorem X.Y → 定理 X.Y；Definition X.Y → 定义 X.Y；Lemma X.Y → 引理 X.Y；Exercise X.Y → 练习 X.Y。

## 翻译风格要求

- 英文原文一字不改地放入引用块；只允许修复 PDF 提取造成的明显排版破损（如连字符断词、错位空格）。
- 译文用简体中文书面语，技术书风格：准确、简洁、流畅，不逐词硬译，不添加解释性内容。
- 「we」译为「我们」，被动语态酌情改为主动；英文长句按中文习惯断句。
- Example / Theorem / Definition 等 environments 的标题（如 **Example 2.1**）保留粗体格式，编号不译。
- 数学推导的可读性优先：公式另起行居中（$$...$$），行内公式用 $...$。
