# 一、基础语法

## 1.1 常用操作

### 1.1.1 工作目录

R 读写文件时，如果没有写绝对路径，就会在**当前工作目录**下找。可以把它理解成命令行里的 `pwd`：先知道"我在哪"，再决定"去哪读写"。

```r
getwd()                 # 查看当前工作目录
setwd("D:/R_work")      # 设置当前工作目录（Windows 路径用 / 或 \\）
```

- `getwd()` 返回一个字符串路径；`setwd()` 没有返回值，但会静默改变后续读写的位置。
- 路径里习惯用正斜杠 `/`，避免 Windows 反斜杠 `\` 在字符串中被当成转义符。

### 1.1.2 赋值

R 用 `<-`（推荐）或 `=` 把值绑定到一个名字上。`<-` 是 R 的惯用写法，也是 tidyverse 代码里的统一风格。

```r
x <- 1:10      # 把整数序列 1,2,...,10 赋给 x
x + 2          # 对向量整体做加法，逐元素加 2
```

> `1:10` 是生成等差序列的简写（见 1.2.1）。R 的运算默认**向量化**——`x + 2` 不是只加第一个元素，而是每个元素都加 2。

### 1.1.3 数学运算

```r
7 + 3     # 加
7 - 3     # 减
7 * 3     # 乘
7 / 3     # 除
7 ^ 3     # 幂（也可写成 7 ** 3）

3 %% 2    # 取模（求余数）→ 1
5 %/% 3   # 整除（取商的整数部分）→ 1
```

- `%%` 与 `%/%` 是 R 里两个"长得很像但语义不同"的运算符，写代码时最容易看混。
- 所有运算都是逐元素进行的，直接作用在整个向量上。

### 1.1.4 比较运算

```r
2 > 1     # TRUE
2 >= 2    # TRUE
2 < 1     # FALSE
2 <= 1    # FALSE
2 == 2    # TRUE  （判断相等用两个等号）
2 != 2    # FALSE （不等）
```

浮点数比较要特别小心：`0.1 + 0.2 == 0.3` 在计算机里其实是 `FALSE`，因为存在二进制表示误差。

```r
identical(2, sqrt(4))          # 严格相等 → TRUE（完全一致才为真）
all.equal(sqrt(2)^2, 2)        # 近似相等 → TRUE（带容差，默认约 1.5e-8）
dplyr::near(sqrt(2)^2, 2)      # 近似相等 → TRUE（dplyr 提供的向量化版本）
```

- `identical()`：要求**完全一致**，对浮点误差零容忍。
- `all.equal()`：允许误差在容差内，返回 `TRUE` 或一段说明差异的文字；判断时通常要 `isTRUE(all.equal(...))`。
- `near()`：`all.equal` 的向量化版本，能直接作用在整个向量上，更适合数据清洗时用。

### 1.1.5 逻辑运算

```r
TRUE | FALSE    # 或 → TRUE
TRUE & FALSE    # 与 → FALSE
!TRUE           # 非 → FALSE
```

`&` / `|` 是**逐元素**的向量化运算；`&&` / `||` 是**短路**运算，只取两边向量的第一个元素、并且一旦结果已确定就不再计算右边。

```r
c(TRUE, FALSE) & c(TRUE, TRUE)    # 逐元素 → TRUE FALSE
c(TRUE, FALSE) && c(TRUE, TRUE)   # 只看第一个 → TRUE

x <- 0
(x != 0) && (1 / x > 0.5)         # 短路：左边为 FALSE，右边不再算，避免除零
```

> 短路的价值在于**安全**：`(x != 0) && (...)` 里如果 x 是 0，右边根本不会执行，就不会出现 `1/0` 的警告。这正是 `&&` / `||` 存在的意义。

## 1.2 数据结构 · 向量

**向量（vector）是 R 最基础的数据结构**：它是一串**同类型**元素组成的一维序列。标量（单个数字、单个字符串）其实也是长度为 1 的向量。可以说 R 里"一切皆向量"，后面的矩阵、数据框都是在向量之上搭起来的。

### 1.2.1 数值向量

最基本的向量是数值向量（numeric），元素是整数或小数。

```r
x <- 3.2          # 长度为 1 的数值向量
x

numeric(5)        # 创建一个长度为 5、全为 0 的数值向量
c(1, 2, 3, c(4, 5))   # c() 合并对象，嵌套的 c() 会被"压平"→ 1 2 3 4 5
```

- `numeric(n)`：预分配一个长度 n、全是 0 的向量，常用于先占位再逐个填值。
- `c(...)`：combine，把多个对象合并成一个向量；它是**扁平化**的，`c(1,2,3,c(4,5))` 等价于 `c(1,2,3,4,5)`。

**生成等差序列**：用 `:` 或 `seq()`。

```r
1:10                 # 1 2 3 ... 10
seq(1, 9, 2)         # 1 3 5 7 9（首项 1，尾项 9，步长 2）
seq(10, by = 10, length.out = 10)   # 10 20 30 ... 100
```

`seq()` 常用参数：

| 参数 | 含义 |
|---|---|
| `from` | 首项（默认 1） |
| `to` | 尾项 |
| `by` | 等差步长（默认 1 或 −1） |
| `length.out` | 序列长度 |
| `along.with` | 以另一对象的长度作为序列长度 |

**生成重复序列**：用 `rep()`。

```r
c <- seq(10, by = 10, length.out = 10)   # 10 20 ... 100
rep(c, 3)                # 整个向量重复 3 遍（长度 30）
rep(b, times = b)        # times 也可以是向量：第 i 个元素重复 b[i] 次
```

`rep()` 常用参数：

| 参数 | 含义 |
|---|---|
| `x` | 要重复的序列 |
| `times` | 序列整体重复次数（可为向量，逐元素指定） |
| `length.out` | 输出序列的目标长度 |
| `each` | 每个元素各自重复的次数（默认 1） |

**向量循环补齐（recycling）**：两个长度不同的向量做运算时，短的会自动重复补齐以配合长的。

```r
b <- c(1, 2, 3, 4, 5)
c <- seq(10, by = 10, length.out = 10)   # 长度 10
b * c        # b 被循环重复到长度 10，再逐元素相乘
```

> 这是个很"方便"但也容易埋坑的规则：长度不整除时 R 会给出警告，结果可能不是你以为的。数据框操作里尤其要留意。

### 1.2.2 逻辑向量

比较运算符作用在向量上，会**逐元素**返回一个逻辑向量（`TRUE` / `FALSE`）。

```r
c(2, 1) > c(1, 3, 3, 1)
# 2>1=T, 1>3=F, 然后短的循环补齐：2>3=F, 1>1=F
# → TRUE FALSE FALSE FALSE
```

用 `%in%` 判断"是否属于集合"：

```r
b <- c(1, 2, 3, 4, 5)
d <- c(1, 3, 5, 7)
d %in% b        # → TRUE TRUE TRUE FALSE
```

- `%in%` 返回左侧**每个元素**是否出现在右侧集合中，结果是和左侧等长的逻辑向量。
- 判断单个值是否相等用 `==`；判断"是否在集合里"用 `%in%`，别混用。

### 1.2.3 字符串向量

字符串用单引号或双引号包裹。若字符串内部本身要出现引号，把内外引号**错开**即可。

```r
'Yangtao is called "yt"'     # 外单内双
"Yangtao is called 'yt'"     # 或者外双内单
```

> 灵活运用错开引号，可以省去大量转义符 `\` 带来的可读性下降。

### 1.2.4 访问向量子集

R 的索引**从 1 开始**（这点和 Python、C 的从 0 开始不同）。

```r
b <- c(1, 2, 3, 4, 5)
b[2:4]        # 第 2~4 个元素 → 2 3 4
b[c(-1, -3)]  # 排除第 1、第 3 个 → 2 4 5
```

- 正索引是"取这些位置"，负索引是"去掉这些位置"；**正负不能混用**，否则报错。
- 用逻辑向量访问：输入一个与原向量等长的逻辑向量，`TRUE` 对应位置被取出。

```r
c <- seq(10, by = 10, length.out = 10)   # 10 20 ... 100
c[c <= 50]     # 取出所有 ≤50 的元素 → 10 20 30 40 50
```

返回**极值所在位置**（而非极值本身）：

```r
which.max(c)   # 最大值的位置 → 10
which.min(c)   # 最小值的位置 → 1
```

> 记忆点：`max(c)` 给的是**值**，`which.max(c)` 给的是**下标**。想按位置继续取别的向量（比如取最大值对应的样本名），就该用 `which.max`。

### 1.2.5 为向量子集赋值

用索引在等号左边，就能"定点替换"元素。

```r
e <- c(2, 4, 6, 8, 10)
e[e < 5] <- 0     # 把所有 <5 的元素替换为 0
e                 # → 0 0 6 8 10

e[7] <- 20        # 对不存在的位置赋值
e                 # → 0 0 6 8 10 NA 20（中间用 NA 补齐）
```

- `e[e < 5] <- 0` 是"逻辑条件批量替换"的经典写法，数据清洗里非常常用。
- 对超出当前长度的位置赋值，R 会把向量**自动加长**，中间空缺的位置填 `NA`（缺失值）。

### 1.2.6 为向量元素命名

创建时用 `名字 = 值` 的形式，就能给每个元素起名字。

```r
f <- c(f1 = 2, f2 = 5, f3 = 8)
f[c("f1", "f3")]   # 按名字取子集 → f1=2, f3=8
f[["f1"]]          # 取出单个元素 → 2
names(f)           # 查看所有名字 → "f1" "f2" "f3"
```

- `[ ]` 取出的仍是向量（可能含多个元素）；`[[ ]]` 只能取出**一个**元素。
- 用 `[[ ]]` 取一个越界的位置或**不存在的名字**时，会直接报错（而 `[ ]` 取不存在的名字会返回 `NA`）。

```r
names(f) <- c("xx", "yy", "zz")   # 批量改名
names(f) <- NULL                  # 移除所有名字
```

### 1.2.7 对向量排序

```r
v1 <- c(2, 7, 3, 5, 4, 8, 6, 2)

sort(v1, decreasing = TRUE)   # 按值降序 → 8 7 6 5 4 3 2 2
```

`sort()` 常用参数：`decreasing`（默认 `FALSE` 升序）、`na.last`（`TRUE` 时把 `NA` 放到末尾）。

`order()` 返回的不是值，而是**"排好序后各元素原本的位置"（索引序列）**：

```r
order(v1)          # → 1 8 3 5 4 7 2 6
v1[order(v1)]      # 用该索引去取值，恰好等于 sort(v1)
```

> 最主要的用途：**给数据框或向量按某列重排**。例如 `df[order(df$age), ]` 就是按 age 升序排整张表——`sort()` 做不到这一点，它只能排一个向量。

`rank()` 返回的是每个元素在全体中的**名次**：

```r
rank(v1)   # 默认 ties.method = "average"，并列时取平均名次
```

- `ties.method` 控制并列值的处理方式（`"average"` 平均、`"first"` 按出现先后、`"min"` / `"max"` 取最小/最大名次等）。
- 最主要的用途：统计学中的**非参数检验、排名分析**。

> 三者的区别一句话记牢：`sort` 给**值**、`order` 给**原位置**、`rank` 给**名次**。

## 1.3 数据结构 · 矩阵与多维数组

矩阵可以理解成"带行列标签的二维向量"；多维数组则是矩阵再向高维推广。R 里**矩阵本身就是二维数组**，所以两者的创建、索引、命名逻辑完全一致，只是维数不同。

### 1.3.1 创建矩阵

用 `matrix()` 把一个向量"折叠"成矩阵。

```r
m1 <- 1:9

m2 <- matrix(data = m1, nrow = 3, byrow = TRUE,
             dimnames = list(c("r1", "r2", "r3"), c("c1", "c2", "c3")))
m2
#    c1 c2 c3
# r1  1  2  3
# r2  4  5  6
# r3  7  8  9
```

`matrix()` 常用参数：

| 参数 | 含义 |
|---|---|
| `data` | 提供元素的向量 |
| `nrow` / `ncol` | 行数 / 列数（给一个即可推出另一个） |
| `byrow` | **是否按行填充**，默认 `FALSE`（即**按列填充**） |
| `dimnames` | 行列名，写成 `list(行名向量, 列名向量)` |

> ⚠️ `byrow` 默认为 `FALSE`，也就是 **R 默认按列把向量填进矩阵**（列优先）。上面若不写 `byrow = TRUE`，`m2` 的第一行会变成 `1 4 7`。这与"按行读表格"的直觉相反，是最容易踩的坑。

也可以先建好矩阵再命名：

```r
rownames(m2) <- c("r1", "r2", "r3")
colnames(m2) <- c("c1", "c2", "c3")
```

矩阵转回向量用 `as.vector()`，**按列读取**：

```r
as.vector(m2)   # → 1 4 7 2 5 8 3 6 9（先读完第 1 列，再读第 2 列……）
```

### 1.3.2 访问矩阵子集

矩阵用 `[行, 列]` 两个下标定位，逗号左边是行、右边是列，**留空表示"该维全选"**。

```r
m2[1, 3]                   # 第 1 行第 3 列 → 3
m2[1:2, 2:3]               # 第 1~2 行、第 2~3 列的子块
m2[2:3, ]                  # 第 2~3 行的所有列（列位留空 = 全选）
m2[-1, -2]                 # 去掉第 1 行、去掉第 2 列
m2[c("r1", "r3"), "c2"]    # 按名字选 → r1 的 c2、r3 的 c2
```

- 行、列位置都支持正索引、负索引、名字、逻辑向量，规则与向量完全一致。
- **逗号不能省**：`m2[2:3, ]` 是"取第 2~3 行的所有列"，而 `m2[2:3]` 是"按一维方式取第 2~3 个元素"，完全是两回事。

按条件筛选元素：

```r
m2[m2 > 4]      # → 7 5 8 6 9（按列顺序取出所有 >4 的元素）
```

> ⚠️ `m2[m2 > 4]` 的结果是**向量而不是矩阵**，并且元素顺序是**按列**排的。想原地替换元素可以反过来用：`m2[m2 > 4] <- NA`。

### 1.3.3 矩阵运算

**逐元素运算**（四则运算 `+ - * /`）：要求两个矩阵**同型**（行列数相同），对应位置分别运算。

```r
m3 <- matrix(1:9, nrow = 3)

m2 * m3      # 逐元素相乘（Hadamard 积）——注意：这不是矩阵乘法
m2 + m3      # 逐元素相加
```

**矩阵乘法**用 `%*%`：A 的**每一行**与 B 的**每一列**做点积，结果放进新矩阵的对应位置。

```r
m4 <- matrix(c(1, 4, 3, 2, 5, 6), nrow = 3)   # 3 行 2 列
m5 <- matrix(c(2, 6, 4, 3, 1, 5), nrow = 2)   # 2 行 3 列

m4 %*% m5     # (3×2) %*% (2×3) → 3×3
# 第一行第一列 = 1×2 + 2×6 = 14
```

- 维度规则：`(m×n) %*% (n×p) → (m×p)`，即**左边列数必须等于右边行数**，否则报错。
- 这才是线性代数意义上的矩阵乘法，与 `*` 的逐元素相乘是两码事。

> 记忆点：`*` 是"同位相乘"（要求同型），`%*%` 是"点积求和"（要求左列数 = 右行数）。

### 1.3.4 创建多维数组

`array()` 把向量折叠成任意维，矩阵是它的二维特例。

```r
a1 <- array(1:24, dim = c(3, 2, 4))   # 3 行 × 2 列 × 4 层
```

`array()` 常用参数：

| 参数 | 含义 |
|---|---|
| `data` | 提供元素的向量 |
| `dim` | 各维长度，如 `c(行, 列, 层, …)` |
| `dimnames` | 各维名称，写成 `list(行名, 列名, 层名, …)` |

创建后也可以整体命名：

```r
dimnames(a1) <- list(c("r1", "r2", "r3"), c("c1", "c2"), c("k1", "k2", "k3", "k4"))
```

查看维度与按坐标取值：

```r
dim(a1)                  # → 3 2 4
a1["r2", "c1", "k3"]     # 第 2 行、第 1 列、第 3 层的元素
```

- 与矩阵一样，方括号里用**逗号分隔每一维**，有几个维度就写几个位置。
- 数组的填充同样遵循**列优先**：先走完第一维，再第二维，再第三维。

> 直觉类比：矩阵是"一张表"，三维数组就是"一叠表"。R 里很多对象本质上是多维数组，理解它有助于后面理解数据框与 `apply` 家族。

## 1.4 数据结构 · 列表

**列表（list）与向量最大的区别是：它不要求元素同型。** 一个列表里可以装数值、字符串、向量，甚至另一个列表。它最大的好处是能把多个不同类型的对象"打包"成一个整体，再按位置或名字分别取出。后面要学的数据框，本质上就是一个"各成分等长的列表"。

### 1.4.1 创建列表

用 `list()` 创建，创建时即可给每个成分起名字。

```r
l1 <- list(A = 1, B = c("yt", "ox", "nabo"), C = 3e4)
l1
# $A
# [1] 1
#
# $B
# [1] "yt"   "ox"   "nabo"
#
# $C
# [1] 30000
```

也可以先创建、再命名：

```r
names(l1) <- c("A", "B", "C")
```

> 直觉类比：向量是"一排同款格子"，列表是"一排任意大小的抽屉"。注意 `l1` 只有 **3 个成分**，但 `l1$B` 那一格里装的是一个长度 3 的向量——成分的"个数"和内容的"长度"是两回事。

### 1.4.2 提取子集与内容

列表有两套提取语法，**返回的东西完全不同**，这是列表最容易混淆的地方。

```r
l1[2]                # 用 [ ] 取子集 → 返回的还是一个列表
l1[c("A", "C")]      # 可以用向量一次取多个

l1$B                 # 用 $ 按名字取出成分的内容
l1[[3]]              # 用 [[ ]] 按位置取出成分的内容
```

`[[ ]]` 相比 `$` 有一个关键优势——**能接受变量传参**：

```r
x <- "B"
l1[[x]]     # 等价于 l1$B
l1$x        # ✗ 错误：$ 不会把 x 当变量，只会去找名叫 "x" 的成分
```

> 记忆点：`[ ]` 是"连盒子一起拿"，返回列表；`$` 和 `[[ ]]` 是"打开盒子拿东西"，返回成分本身。想用变量指定名字，只能用 `[[ ]]`。

### 1.4.3 为列表成分赋值

```r
l1$D <- 0.5        # 给不存在的成分赋值 → 列表自动新增一个成分
l1

l1[c("A", "D")] <- list(A = "WZT", D = 1.5)   # 批量赋值（右侧必须用 list() 包起来）
l1

l1["D"] <- NULL    # 赋值为 NULL → 移除该成分
l1
```

- 批量赋值时右侧**必须**是 `list(...)`；直接写向量会被拆开，结构对不上。
- 删除成分用 `<- NULL`：`l1["D"] <- NULL` 或 `l1[["D"]] <- NULL` 都可以。

### 1.4.4 列表与向量的互转

```r
y <- c(a = "yt", b = 2.6)     # 注意：c() 是"向量"构造函数
y                             # → a="yt"  b="2.6"
typeof(y)                     # → "character"

l2 <- as.list(y)              # 向量 → 列表：每个元素独立成一个成分
l2
# $a
# [1] "yt"
# $b
# [1] "2.6"

y2 <- unlist(l2)              # 列表 → 向量：压回一维
typeof(y2[2])                 # → "character"
```

> ⚠️ 这里有个容易误读的点：`typeof(y2[2])` 是 `"character"`，**并不是 `unlist()` 造成的**。`c(a = "yt", b = 2.6)` 在**创建向量时**就已经把 `2.6` 强制转成了 `"2.6"`——因为向量要求所有元素同型。`as.list()` / `unlist()` 只是在列表和向量之间搬运，没有改变类型。
>
> 想真正观察 `unlist()` 的类型强转，得用**直接构造的混合类型列表**：

```r
l3 <- list(a = "yt", b = 2.6)   # 列表不要求同型，b 仍是数值
l3$b                            # → 2.6（数值）

unlist(l3)                      # → "yt" "2.6"：到这一步才发生强转
```

- 强转遵循"向下兼容"：`character > double > integer > logical`，只要有一个是字符型，整条结果都会变成字符型。
- 这也是 `unlist()` 要慎用的原因——它会**静默丢类型**，`2.6` 一旦变成 `"2.6"` 就不能再做数值运算了。

### 1.4.5 purrr：筛选类函数

`purrr` 是 tidyverse 家族里专门做列表 / 函数式编程的包。先准备一份"半结构化的用户数据"（层级嵌套、含 API 超时产生的 `NULL`、混有测试账号）：

```r
library(purrr)

raw_users <- list(
  user1 = list(name = "Alice", status = "active", score = 85, is_test = FALSE,
               contact = list(city = "北京", phone = "1380001")),
  user2 = NULL,   # API 超时 / 用户不存在，返回了空值
  user3 = list(name = "Bob", status = "inactive", score = 42, is_test = FALSE,
               contact = list(city = "上海", phone = "1390002")),
  user4 = list(name = "Test_User", status = "active", score = 99, is_test = TRUE,
               contact = list(city = "广州", phone = "1370003")),
  user5 = list(name = "David", status = "active", score = 90, is_test = FALSE,
               contact = list(city = "深圳", phone = "1360004"))
)
```

**`compact()`：删掉空元素**

```r
clean_users <- compact(raw_users)
names(clean_users)   # → "user1" "user3" "user4" "user5"（user2 这个 NULL 被删掉）
```

> ⚠️ `compact()` 删的是 **`NULL` 和长度为 0 的元素**，**不会删 `NA`**——`NA` 是一个"有值"的缺失标记，不算空。

**`discard()` / `keep()`：按条件删 / 留**

```r
real_users <- discard(.x = clean_users,
                      .p = \(single_user) single_user$is_test == TRUE)
names(real_users)   # → "user1" "user3" "user5"（user4 是测试账号，被丢掉）

vip_users <- keep(.x = real_users,
                  .p = \(single_user) single_user$score >= 80)
names(vip_users)    # → "user1" "user5"
```

- `.p` 是一个**返回 TRUE / FALSE 的函数**（叫"谓词"），purrr 会把它依次作用到每个成分上。
- `discard()` 丢掉 `.p` 为 `TRUE` 的；`keep()` 留下 `.p` 为 `TRUE` 的——**两者正好相反**。
- `\(single_user) ...` 是 **R 4.1+** 的匿名函数简写，完全等价于 `function(single_user) ...`。

`discard` / `keep` 的本质是"把循环藏起来"：你只写判断逻辑，循环与挑拣由 purrr 代劳。用 Python 的写法对照：

```python
def check_test(single_user):
    return single_user["is_test"] == True

real_users = []
for single_user in clean_users:
    if not check_test(single_user):   # discard：为 True 就扔，为 False 才留
        real_users.append(single_user)
```

> 对照记忆：`keep` ≈ Python 的 `filter`；`discard` ≈ `filter` 取反。R 里没有 Python 那样的列表推导式，`purrr` 就是用来填这个坑的。

### 1.4.6 purrr：提取与重组函数

**`pluck()`：按层级深层取值**

```r
city_user1 <- pluck(.x = vip_users, "user1", "contact", "city")
city_user1   # → "北京"
```

- `pluck(list, "a", "b", "c")` 等价于 `list[["a"]][["b"]][["c"]]`，但写法短得多。
- 关键好处：**取一个不存在的层级不会报错，而是安全返回 `NULL`**（用 `[[ ]]` 链式取值则会在中途断掉）。

**`append()`：在列表末尾追加元素**

```r
new_user <- list(name = "Eva", status = "active", score = 95, is_test = FALSE,
                 contact = list(city = "杭州", phone = "1350005"))

vip_users_updated <- append(vip_users, list(user6 = new_user))
names(vip_users_updated)   # → "user1" "user5" "user6"
```

- `append()` 是 **base R 的函数**（不属于 purrr），对列表同样适用。
- 第二个参数要**用 `list(user6 = ...)` 包起来**：直接传 `new_user` 会把它的 5 个成分当作 5 个新元素拼进去，而不是作为一个整体追加。

**`flatten()`：摊平一层嵌套**

```r
page_1 <- list(user1 = list(name = "Alice", score = 85, is_test = FALSE),
               user2 = list(name = "Test_User", score = 99, is_test = TRUE))
page_2 <- list(user3 = list(name = "Bob", score = 42, is_test = FALSE),
               user4 = list(name = "David", score = 90, is_test = FALSE))

api_results <- list(page_1, page_2)   # 分页结果：列表套列表
all_users <- flatten(api_results)     # 撕掉"页"这一层，4 个用户合并到同一层
length(all_users)                     # → 4
```

- `flatten()` **只摊平一层**：`api_results` 是"页 → 用户"两层，摊平后变成"用户"一层；若还有更深的嵌套，需要再调用一次。
- ⚠️ **版本提示**：`flatten()` 在 **purrr 1.0.0（2022-12）** 中已被 **`list_flatten()`** 取代（superseded）。老写法仍能运行，但官方不再推荐、只做关键 bug 修复，新代码建议直接用 `list_flatten()`。

purrr 常用函数速览：

| 函数 | 作用 | 备注 |
|---|---|---|
| `compact(x)` | 删掉 `NULL` 与长度 0 的元素 | **不删 `NA`** |
| `discard(.x, .p)` | 删掉 `.p` 为 `TRUE` 的元素 | `.p` 是谓词函数 |
| `keep(.x, .p)` | 保留 `.p` 为 `TRUE` 的元素 | 与 `discard` 相反 |
| `pluck(.x, ...)` | 按层级取值 | 缺失层级安全返回 `NULL` |
| `flatten(.x)` | 摊平一层 | 已被 `list_flatten()` 取代 |
| `list_flatten(.x)` | 摊平一层（新版写法） | purrr 1.0.0 起推荐 |

## Z. 易错点备忘

- **索引从 1 开始**：R 的下标是 1-based，和 Python / C 的 0-based 不同。
- **正负索引不能混用**：`x[c(1, -2)]` 会报错。
- **`=` 与 `==`**：赋值用 `<-`，判断相等用 `==`，别写反。
- **浮点数不要用 `==` 直接比**：`0.1 + 0.2 == 0.3` 是 `FALSE`，改用 `near()` / `all.equal()`。
- **`&` / `|` 与 `&&` / `||` 不同**：前者逐元素向量化，后者短路且只看第一个元素。
- **向量循环补齐**：长度不一致的向量运算会自动补齐短的，长度不整除时结果可能出乎意料（有警告）。
- **`[ ]` 与 `[[ ]]`**：前者取子集（可能多个），后者只取一个元素；`[[ ]]` 取不到会报错。
- **`sort` / `order` / `rank` 三者语义不同**：分别返回值、原位置、名次。
- **`NA` 是缺失值**，不是 `NULL`；`NA` 参与运算结果仍是 `NA`（需用 `na.rm = TRUE` 等参数处理）。
- **`mean` / `sum` 等聚合函数遇到 `NA`**：默认返回 `NA`，需显式写 `na.rm = TRUE`。
- **`matrix()` 默认按列填充**：`byrow` 默认为 `FALSE`，想按行填必须显式写 `byrow = TRUE`。
- **`*` 与 `%*%` 完全不同**：`*` 是同型逐元素相乘，`%*%` 才是矩阵乘法（要求左列数 = 右行数）。
- **`m[m > 4]` 返回的是向量**，不是矩阵，而且元素按**列**顺序排列。
- **矩阵下标的逗号不能省**：`m[2:3]`（按一维取第 2~3 个元素）≠ `m[2:3, ]`（取第 2~3 行的所有列）。
- **`as.vector()` 按列读取**，不是按行。
- **列表 `[ ]` 与 `[[ ]]` 返回的东西不同**：`l[1]` 返回**列表**（子集），`l[[1]]` 返回**成分本身**。
- **`$` 不接受变量**：`l$x` 只会去找名为 "x" 的成分；想用变量指定名字，必须写 `l[[x]]`。
- **批量给列表成分赋值要用 `list()`**：`l[c("A","D")] <- list(A = …, D = …)`，右侧直接写向量会出错。
- **`c()` 在创建向量时就已强转类型**：`c(a = "yt", b = 2.6)` 里的 `2.6` 建出来就是 `"2.6"`，不是 `unlist()` 干的。
- **`unlist()` 会静默强转类型**：混合类型按 `character > double > integer > logical` 统一，数值可能变成字符串而失去运算能力。
- **`append()` 追加列表元素要包一层 `list()`**：`append(x, list(new = v))`；直接传会把它拆成多个元素。
- **`compact()` 不删 `NA`**：只删 `NULL` 与长度为 0 的元素。
- **`flatten()` 已被 `list_flatten()` 取代**（purrr 1.0.0），老写法仍可用但不再推荐。
